# Phase boundaries

A phase ends when one kind of work is complete, such as planning, implementation, or verification. Make context decisions at that boundary, not halfway through the work.

Use the first option that fits:

1. Continue in the current session when the next phase needs the discussion or there is enough context room.
2. Use the built-in clear operation when the current context is no longer useful.
3. Send a tightly scoped task to a subagent when it can run independently and return a report.
4. Use the built-in compact operation when the context still matters but the session needs more room.

Continue when uncertain. It preserves the original reasoning, while clearing and compacting can discard detail.
